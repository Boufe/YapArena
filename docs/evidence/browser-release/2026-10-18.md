## Corrections established while implementing

Earlier failed runs are not accepted as passes. Diagnostics identified macOS locale
initialization making the native PostgreSQL postmaster multithreaded; the launcher
now supplies the fixed C locale. Browser assertions were scoped to the receipt rather
than identical order-table cells, and wait for the new scope's form before checking
its balance. Repeated cases use independent accounts and close completed pages so
existing A4 per-account throttles remain intact. These are fixture/synchronization
changes; no production economics, authorization, timing or rate controls changed.

The previously documented random execution assertion is replaced with fixed inputs
before commitments, default exploration remains 5%, and exact expected outcomes are
asserted. No retry, threshold reduction or forced-production execution was introduced.
