## Functional and quality results

Node **24.19.0**, local Chrome, Playwright Core and the existing Node test runner
were used. No dependency was added.

- `npm run build`: passed, including the new approximately 32 KB minified homepage
  bundle and existing media/replay bundles.
- `npm run check`, through the existing `A4_QUALITY=true DATABASE_TEST_MODE=host`
  disposable-database verifier: **498 passed, zero failed, zero skipped**.
  Coverage: **94.38% lines, 93.45% branches, 95.85% functions**.
- Fresh and upgraded PostgreSQL isolation: passed, including the 19 membership
  guard cases, runtime/backend/worker journeys and existing wallet, revocation
  and A4 regression identities. Hosted SQL/API isolation was not reverified.
- `git diff --check`: passed.
- `scripts/verify-homepage-browser.js`: passed the six-width comparison,
  per-idea arguments/debate matching, forward/backward 620ms direction/easing,
  rapid navigation without duplicate IDs or focus loss, single-clock progress
  over repeated cycles, elapsed-time pause/resume, participation/hidden/offscreen
  suspension, 32-second upward argument flow and pause, both chart sizes with
  interpolated pointer/touch/keyboard inspection and restoration, independent
  expansion with sorting/filtering/resizing and focus preservation, local demo
  preview/follows, search/categories/Following, reduced motion and coarse-pointer
  mobile touch emulation.
- Real adapter/browser integration: nullable history, actual wallet response,
  authenticated PUT/DELETE follows without duplicate handlers, canonical debate
  and account navigation, no homepage media SDK/session, no-JavaScript SSR links
  and explicit 503 fallback passed. These use synthetic local HTTP fixtures,
  not a claim of hosted account acceptance.
- **Zero** captured console exceptions, CSP violations or axe WCAG A/AA violations
  in the checked native homepage states.
- Existing `scripts/verify-hero-browser.js`: passed actual muted WebM playback,
  one shared preview budget, replay loop, thumbnail fallback, hover/focus handoff,
  cancellation, hidden/offscreen release, entry, data saving, mobile and reduced
  motion checks after the homepage navigation update.

Reproduce with the commands in the [homepage contract](../../wide-homepage.md#verification).
The original HTML is required for visual comparisons and is intentionally not
committed. No hosted media provider, physical device, screen reader, load trial,
production container build or deployment was performed for this homepage task.
Existing CI remains required before review acceptance.

## Data limitations

Published topics/debates, canonical routes, real follows and the existing account/
Yap Coins display are connected. The view is bounded to 12 topics and nine playable
debates. Topic-level market and argument histories remain unavailable and are
shown as stable placeholders; A4 settlement/private round information is not
substituted. The exact sample series, rates and viewers are confined to explicitly
enabled development/test reference mode, clearly labeled as illustrative. Sample
positions/follows remain local and never submit an order or spend coins.
