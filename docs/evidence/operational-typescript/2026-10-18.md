  backpressure fixture therefore exceeds the existing 500-character column limit.
  This environment limitation is reproduced before/after; Docker UTF-8 passes.
  Neither initialization defaults, fixture nor schema is changed.

  third argument to `assert.rejects`; a precise local type projection retains that
  call instead of changing its arguments.

  object. It establishes narrow viewport behavior; it does not establish that those
  two context-emulation options take effect. Its existing options remain unchanged.

sustained hosted capacity or paid-release readiness. No hosted resources are used.
