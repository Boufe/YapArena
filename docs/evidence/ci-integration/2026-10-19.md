homepage's public-bots chart to refresh. `frontend/homepage.ts` intentionally

[Playwright documents foreground selection](https://playwright.dev/docs/api/class-page#page-bring-to-front).

PR #38's [integration run 39167198907](https://github.com/Boufe/YapArena/actions/runs/39167198907)
passed its native UTF-8 smoke and browser gates, then failed the community stress
shutdown assertion: exit 1 rather than 0. That historical process suppressed
stderr, so its exact exception was not captured. Inspection found delivery
cancellation destroys checked-out PostgreSQL sockets without a client error
listener. The installed node-postgres client rejects active queries and also
emits `error` on unexpected disconnect; an unobserved event can terminate Node.
See the [client error-event contract](https://node-postgres.com/apis/client).

The maintained regression now models both query rejection and the client error
event for read/prune under shutdown/deadline cancellation. With only the test
change, the regression failed with an unwanted `connection closed` exception.
Delivery now installs a temporary error listener, marks failed clients for discard,
and removes the listener before release. All four regression cases verify rejection,
one failed release, listener removal and refusal of subsequent work. SQL,
transactions, the three-second statement timeout, four-second connection deadline,
shutdown ordering, process deadlines and recovery assertions are unchanged.
